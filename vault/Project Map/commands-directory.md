# תיקיית הפקודות (.claude/commands/)

## מה התיקייה עושה

`.claude/commands/` מכילה פקודות מותאמות (slash commands) להפעלה מהירה של תהליכים. פקודות נוצרות כקבצי Markdown ומופעלות ע"י `/שם-הפקודה` בשיחה.

**דוגמאות לפקודות עתידיות:**
- `/create-post` — תהליך מלא ליצירת פוסט (חן חוקרת → יעל כותבת → יובל מעצב)
- `/review-content` — סקירת תוכן ע"י הצוות
- `/brief` — יצירת Content Brief חדש

## מצב נוכחי

**ריקה** — מכילה רק `.gitkeep`.

## למי התיקייה שייכת

**ראובן** — הוא זה שמחליט אילו workflows להפוך לפקודות מהירות. פקודות הן קיצורי דרך לפרוטוקולים שראובן מנהל.
