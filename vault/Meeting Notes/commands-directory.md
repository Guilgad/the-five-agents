# Commands Directory

## Overview
תיקיית `.claude/commands/` מיועדת לפקודות מותאמות (custom slash commands) לביצוע מהיר של תהליכים חוזרים. כרגע ריקה עם `.gitkeep` בלבד. פקודות אלה יאפשרו הפעלת תהליכי עבודה מלאים בפקודה אחת — לדוגמה `/publish-post` או `/research-topic`.

**מיקום בפרויקט:** `/.claude/commands/`
**שייך ל:** ראובן (מנכ"ל) — הפקודות מהוות קיצורי דרך לתהליכים שהוא מנהל.

### מה צפוי להיות כאן
פקודות slash מותאמות לתהליכים נפוצים של הצוות, לדוגמה:
- תהליך יצירת תוכן מקצה לקצה
- תהליך חקירה + כתיבה + עיצוב
- פרסום תוכן גמור
