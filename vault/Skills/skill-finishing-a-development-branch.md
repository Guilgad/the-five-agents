# Skill: finishing-a-development-branch

## מה הסקיל עושה

מנחה את שלב הסיום של branch פיתוח: הצגת אפשרויות (merge, PR, cleanup), בדיקת קריטריונים לשחרור, וסיוע בהחלטה על הדרך הנכונה לסיים את העבודה.

- כשכל הטסטים עוברים
- לפני החלטה על merge/PR/cleanup
