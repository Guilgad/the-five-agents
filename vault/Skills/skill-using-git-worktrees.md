# Skill: using-git-worktrees

## מה הסקיל עושה

מנחה שימוש ב-git worktrees — יצירת עותק עובד נפרד של ה-repository לעבודה במקביל על מספר branches ללא החלפת branch. שימושי לבידוד features ולביצוע תוכניות.

## מתי להפעיל

- לפני עבודה על feature שצריכה isolation
- לפני executing plans
- כשרוצים לעבוד על branch בלי לעזוב את ה-main branch
