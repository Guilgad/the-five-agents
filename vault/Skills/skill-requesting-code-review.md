# Skill: requesting-code-review

## מה הסקיל עושה

מנחה את תהליך בקשת code review בצורה אפקטיבית — מה לכלול בבקשה, כיצד להציג את השינויים, ומה לבדוק לפני שמבקשים review.

## מתי להפעיל

- בסיום implementation של feature
- לפני merge ל-main
- כשצריך עיני reviewer על קוד חשוב
