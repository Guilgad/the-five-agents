# Skill: receiving-code-review

## מה הסקיל עושה

מנחה כיצד לקבל ולעבד code review feedback בצורה נכונה. דורש ריגור טכני — אימות שההצעות נכונות, הבנת הסיבות, ובדיקת edge cases. מונע "performative agreement" (הסכמה עיוורת ללא הבנה).

## מתי להפעיל

- אחרי קבלת code review
- לפני implementation של הצעות reviewer
- כשהצעת reviewer נראית לא ברורה או שנויה במחלוקת טכנית
