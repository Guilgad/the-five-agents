# Skill: obsidian-markdown

## מה הסקיל עושה

מנחה כתיבה ועריכה של Obsidian Flavored Markdown — syntax מיוחד של Obsidian הכולל wikilinks, callouts, frontmatter properties, tags, ו-embeds.

## מתי להפעיל

- כשיוצרים או עורכים קבצי `.md` ב-Obsidian
- כשמשתמשים ב-wikilinks `[[]]`, callouts `> [!note]`, frontmatter
- עבודה עם הוולט

## syntax עיקרי

```markdown
[[wikilink]]              # קישור לנוט אחר
[[note#section]]          # קישור לסעיף ספציפי
![[embed]]                # הטמעת נוט
> [!note] כותרת          # Callout
---                       # מפריד frontmatter
tags: [tag1, tag2]        # תגיות
```
